# JustWrites website

A responsive, static website concept for JustWrites, built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser. No build step is required.

## Deploy with GitHub Pages
1. Create a new repository on GitHub named `justwrites` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and the `README.md` file.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/justwrites/`.

## Before sharing publicly
- Replace the Instagram placeholder URL with the official JustWrites profile.
- Confirm the final product names, prices, and product files before offering them for sale.
- This is currently a front-end demo: it does not process payments, authenticate customers, or deliver paid downloads. Add a trusted checkout/digital-delivery service before accepting payments.
- Use only artwork, fonts, and other assets you have permission to use. Google Fonts are loaded online.
